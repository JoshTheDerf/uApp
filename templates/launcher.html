uApp Demo

A .uapp file is a single-file application. It contains the UI, database, and files all together, like a spreadsheet, but it runs like an app. Open it, edit it, share it via email or network share. No server needed.

These sample apps run entirely in your browser. Changes are saved locally. Download your modified copy to share with others.

      How it works

      A .uapp file is a SQLite database containing:

      • Compressed web app files in sqlar archive format (the app UI)
      • Whatever tables and data the app stores (user data)

      When opened, a built-in web server serves the files in the /app folder and injects plumbing to let the app read and write to the database. Apps can also be modified with an integrated AI chat, SQL browser, and file editor.
